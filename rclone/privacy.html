NicOS rclone Reader — Privacy Policy

Effective date: October 31, 2026

This policy covers the owner's personal Google Drive read-only connection through rclone, and this informational website. It does not cover the separate Smart Tab Groups Chrome extension.

Information accessed

With the owner's Google authorization, rclone can read file names, identifiers, metadata and contents within the Google Drive account according to the granted read-only scope. The local workflow uses these reads to inspect and verify backups, including hashes of preserved files. The OAuth client does not request write, modify or delete permission for Google Drive.

Purpose and limited use

Google user data is accessed only for the owner's requested backup checks, file comparison and integrity verification. It is not used for advertising, profiling, resale, model training, or unrelated purposes.

Storage and sharing

rclone runs on the owner's own computer. Local credentials and verification artifacts are kept in the owner's local configuration/workflow environment; some backup files are held in the owner's own Google Drive account. This static GitHub Pages website does not ask for Google sign-in, receive OAuth tokens, upload Drive file contents, or maintain a developer-operated database. The utility does not intentionally transfer Google user data to a third-party analytics or advertising service. Google's own service processes authorized Drive requests, and the public website is hosted by GitHub subject to its hosting and access-log practices.

Data retention, control and deletion

The owner manages their own Drive files, local copies, verification records and rclone credentials. The owner may stop using the utility, delete local data and revoke the connection via Google Account third-party connections. Revoking access prevents future authorized reads, though it does not automatically erase existing local or Drive backup files.

Security

The utility uses Google OAuth through rclone. This website does not contain or publish client secrets, access tokens, refresh tokens or private backups. Actual local credential and file security remain under the owner's device and account settings.

Google API Services policy

Use and transfer of information received from Google APIs follow the Google API Services User Data Policy, including its Limited Use requirements.

Contact

For questions about this personal utility, contact its maintainer through the repository.
