Claude Project Tabs - Privacy Policy

Effective Date: June 24, 2026

Overview

Claude Project Tabs ("the Extension") is a Chrome extension that maps Chrome tab groups to Claude.ai Projects for better workflow organization. This policy explains what data is collected and how it is used.

Data Collection

The Extension collects and stores the following data locally on your device only:

Data Type Storage Location Purpose
Project URL → Tab Group ID mapping chrome.storage.sync Remembers which tab group belongs to which Claude Project
User preferences (if any) chrome.storage.sync Saves your settings

No data is ever sent to any external server.

Permissions Explained

Permission Why Needed
tabs To detect current tab URL and create new tabs
tabGroups To create, update, and manage tab groups
storage To save project↔group mappings locally
scripting To scan the Claude.ai Projects page for project names
contextMenus To add "Bind to Project" right-click menu

Data Sharing

We do not collect, share, or sell any user data. All data stays on your local device via Chrome's storage.sync API.

Third-Party Services

None. The Extension operates entirely offline and does not communicate with any external servers.
