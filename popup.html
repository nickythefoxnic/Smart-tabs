Open a Claude or ChatGPT project inside an existing tab group, then right-click the page and choose “Bind page to Tab”. You can also paste a Project URL below. Binding never changes the group name or color.
Project BindingsOne row per tab group
To bind manually: open a Project, copy its URL, paste it next to the intended tab group, and click Bind. New tabs opened inside that group will open the linked Project.
